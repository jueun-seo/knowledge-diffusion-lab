## 개념 설명
### uv `개발 환경`
파이썬 프로젝트를 만들고(uv init), 패키지를 설치하고(uv add), 가상환경을 관리하고, 그 안에서 명령을 실행하는(uv run) 일을 도구 하나로 처리해요. 예전에는 pip, venv 같은 도구를 따로 썼는데 uv가 이걸 합쳤고, 설치 속도도 매우 빨라요. uv add로 설치하면 pyproject.toml과 uv.lock에 자동으로 기록돼서, 다른 사람도 uv sync 한 번으로 똑같은 환경을 만들 수 있어요.

### 가상환경(.venv) `개발 환경`
프로젝트마다 따로 쓰는 파이썬 실행 공간이에요. 그 안에 파이썬 실행 파일과 이 프로젝트에서 설치한 패키지만 들어가요. 그래서 A 프로젝트와 B 프로젝트가 서로 다른 버전의 FastAPI를 써도 부딪히지 않아요. .venv 폴더는 언제든 다시 만들 수 있어서 Git에는 올리지 않고(.gitignore), 대신 pyproject.toml과 uv.lock을 올려요.

### uv run `개발 환경`
'가상환경 켜기 → 명령 실행'을 한 번에 해 주는 명령이에요. 그래서 가상환경을 직접 활성화(activate)하지 않아도 uv run 뒤의 명령은 .venv 안의 python과 fastapi로 실행돼요. 실행 전에 pyproject.toml에 적힌 패키지가 실제로 설치돼 있는지 확인하고, 모자라면 맞춰 줘요.

### pyproject.toml `개발 환경`
프로젝트의 신분증 겸 장보기 목록이에요. 프로젝트 이름, 필요한 파이썬 버전(requires-python), 필요한 패키지 목록(dependencies)이 적혀 있어요. uv는 지금 폴더에서 위쪽 폴더로 올라가며 이 파일을 찾고, 찾은 폴더를 프로젝트 기준점으로 삼아요. 그래서 backend 폴더 안에서 실행해도 상위 mini-insta 폴더의 .venv가 쓰였어요.

### 상대 경로 `개발 환경`
지금 내가 있는 폴더를 기준으로 파일 위치를 적는 방법이에요. backend 폴더 안에서는 main.py, 그 위 폴더에서는 backend/main.py가 같은 파일을 가리켜요. 처음부터 끝까지 다 적는 방식은 절대 경로라고 해요(예: C:/Users/u/practice/mini-insta/backend/main.py). 헷갈릴 때는 터미널에서 pwd로 지금 위치부터 확인하면 돼요.

### cd와 파일 경로 `개발 환경`
cd(change directory)는 폴더 사이를 이동하는 명령이에요. 그래서 파일인 main.py로는 들어갈 수 없고 'Not a directory' 같은 오류가 나요. cd ..은 한 단계 위로, cd backend는 아래 backend 폴더로 가요. 파일은 이동하는 곳이 아니라 명령에 넘겨주는 재료예요(예: uv run fastapi dev main.py).

### 127.0.0.1(내 컴퓨터) `개발 환경`
'바로 지금 이 컴퓨터'를 뜻하는 특별한 주소예요. localhost와 같은 뜻이에요. 개발 서버를 이 주소로 띄우면 내 컴퓨터에서만 접속할 수 있고, 다른 사람은 들어올 수 없어요. 뒤에 붙는 :8001은 이 컴퓨터 안에서 몇 번 문(포트)으로 들어갈지를 뜻해요.

### FastAPI 개발 서버 `Backend`
fastapi dev main.py는 main.py 안의 app을 찾아서 개발용 서버로 띄워요. 코드를 저장하면 서버가 자동으로 다시 시작돼서(reload) 고친 내용이 바로 반영돼요. 실제 서비스를 띄울 때는 fastapi run을 쓰는데, 이때는 자동 재시작이 꺼져요. 서버를 끄려면 터미널에서 Ctrl+C를 눌러요.

### 라우트(엔드포인트) `Backend`
'이 주소로 이런 방식의 요청이 오면 이 함수를 실행한다'는 규칙 하나예요. 주소(/posts)와 요청 방식(GET)이 한 쌍이에요. 등록되지 않은 주소로 요청하면 FastAPI는 404 Not Found를 돌려줘요. 지금 등록된 라우트 목록은 /docs 화면에서 한눈에 볼 수 있어요.

### GET 요청 `Backend`
서버에서 데이터를 '가져오기만' 하는 요청 방식이에요. 브라우저 주소창에 주소를 치고 들어가는 것도 GET이에요. 데이터를 새로 만들 때는 POST, 고칠 때는 PUT이나 PATCH, 지울 때는 DELETE를 써요. 같은 /posts 주소라도 GET과 POST는 서로 다른 함수에 연결할 수 있어요.

### JSON 응답 `Backend`
JSON은 프로그램끼리 데이터를 주고받을 때 쓰는 글자 형식이에요. 파이썬의 리스트·딕셔너리와 생김새가 거의 같아서, FastAPI는 함수가 돌려준 리스트나 딕셔너리를 자동으로 JSON 글자로 바꿔 보내요. 다른 점도 있어요. JSON은 큰따옴표만 쓰고, 파이썬의 True, None 대신 true, null을 써요.

### Not Found(404) `Backend`
요청한 주소에 해당하는 라우트가 없을 때 서버가 돌려주는 상태 코드예요. 주소 오타, 다른 포트의 서버에 접속한 경우, 다른 파일을 실행한 경우에 자주 봐요. 자주 보는 상태 코드는 200(성공), 404(없음), 422(요청 형식이 틀림), 500(서버 코드 오류)이에요.

### /docs 자동 문서 `Backend`
FastAPI가 등록된 라우트를 읽어서 자동으로 만들어 주는 API 설명서 화면이에요(Swagger UI). 라우트를 펼치고 'Try it out' → 'Execute'를 누르면 브라우저에서 바로 요청을 보내고 응답을 볼 수 있어요. /redoc 주소로 가면 모양이 다른 설명서도 있어요.

### 포트 `Backend`
한 컴퓨터 안에서 여러 프로그램이 동시에 통신할 수 있도록 나눠 둔 문 번호예요. 주소(127.0.0.1)가 건물이라면 포트(8000, 8001)는 호수예요. FastAPI 개발 서버는 기본으로 8000번을 쓰고, --port 옵션으로 바꿀 수 있어요.

### 포트 충돌 `Backend`
한 포트는 한 번에 한 프로그램만 쓸 수 있어요. 8000번을 이미 다른 서버가 쓰고 있으면 새 서버가 뜨지 못하거나(Address already in use), 브라우저가 엉뚱한 서버의 화면을 보여줘요. 오늘 Not Found와 다른 API 화면이 보인 게 이 경우였어요. 해결법은 다른 포트로 띄우거나, 먼저 떠 있는 서버를 Ctrl+C로 끄는 거예요.

### 데코레이터 `Python 기초`
함수 바로 위에 @로 붙여서 그 함수에 기능을 덧씌우는 문법이에요. @app.get("/posts")는 '아래 함수를 /posts의 GET 요청 담당으로 등록해 줘'라는 뜻이에요. 함수 내용은 그대로 두고, FastAPI가 주소와 함수를 짝지은 목록에 올려 두는 거예요.

### 함수 `Python 기초`
이름을 붙여 둔 작업 묶음이에요. def 이름(): 으로 만들고, 이름()으로 부르면 안의 코드가 실행돼요. return은 결과를 부른 쪽에 돌려주고 함수를 끝내요. FastAPI에서는 내가 직접 부르지 않고, 요청이 들어오면 FastAPI가 대신 불러 줘요.

### 리스트 `Python 기초`
여러 값을 순서대로 담는 상자예요. [] 안에 쉼표로 나눠 적고, 0번부터 시작하는 번호로 꺼내요(posts[0]이 첫 번째). 나중에 추가(append)하거나 지울 수 있어요. 게시물처럼 같은 종류가 여러 개일 때 써요.

### 딕셔너리 `Python 기초`
'이름표: 값' 쌍을 모은 카드예요. {} 안에 키와 값을 콜론(:)으로 묶어 적어요. 번호 대신 이름표로 꺼내요(post["caption"]). 게시물 하나가 가진 여러 정보(id, caption)를 한데 묶을 때 써요.

### 키-값 쌍 `Python 기초`
딕셔너리를 이루는 한 칸이에요. 키는 이름표이고 같은 딕셔너리 안에서 겹치면 안 돼요. 값은 그 이름표에 붙은 내용이에요. "id": 1에서 "id"가 키, 1이 값이에요. JSON 객체도 같은 구조라서 API 응답에 그대로 쓰여요.

### 쉼표 문법 `Python 기초`
리스트, 딕셔너리, 함수 인자에서 항목과 항목 사이를 나누는 기호예요. 항목 사이에 쉼표가 빠지면 SyntaxError가 나요. 마지막 항목 뒤에 붙이는 쉼표는 파이썬에서는 괜찮아서, 줄을 추가할 때 실수를 줄여 줘요. 단, JSON에서는 마지막 쉼표가 오류예요.

### import `Python 기초`
다른 파일이나 패키지에 있는 기능을 지금 파일로 가져오는 문법이에요. from fastapi import FastAPI는 'fastapi 패키지 안에서 FastAPI라는 이름만 꺼내 와'라는 뜻이에요. 가져오지 않은 이름을 쓰면 NameError가 나요. 패키지가 설치돼 있지 않으면 ModuleNotFoundError가 나는데, 그때는 uv add로 설치해요.

### FastAPI 앱 객체 `Backend`
app = FastAPI()는 서버의 본체를 하나 만드는 줄이에요. 이후 @app.get, @app.post로 만드는 모든 라우트가 이 app에 등록돼요. fastapi dev main.py를 실행하면 FastAPI가 main.py 안에서 app이라는 이름을 찾아 서버로 띄워요. 그래서 이름을 바꾸면 실행 명령도 맞춰야 해요.
